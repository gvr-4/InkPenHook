●ボタン名
	Barrel	//デフォルト：マウス右ボタンエミュレートされる
	Eraser	//デフォルト：これを押したままペン先をタッチすると消しゴムペンとして動作（消しゴム未対応アプリには何も起きない）
	tip		//デフォルトでペン先．マウス左ボタンにエミュレートされる．

●イベント名
	ShortPress	//短時間で離されたとき．マウスエミュレートでクリック．
	LongPress	//ショートを超える時間押され続けているとき，マウスエミュレーションでは長押し，ドラッグなど．
	
●方法
	replace		//イベントをもみ消し，代わりに指定された機能を発行する
	parallel	//イベントはそのままアプリに渡し，指定された機能を発行する
	defalut		//イベントはそのままアプリに渡し，なにも手を付けない
●機能
	ScanCode, values	//スキャンコード(Values)を順に発行する
	MouseFunc, values	//マウス機能(values)を発行する．
●値
	value	{ a }		// １つの値	
	values{ a, b, c,...}	// 複数の値のリスト
