機能
InkPenHook.exe は，Dynabook F8, V8に付属しているスタイラスペン(WACOM AES)のサイドボタン(Eraser, Barrel)をOS標準の消しゴム，右クリック以外のキーボードスキャンコードに置き換える常駐ツールです．

InkPenHook がカスタマイズできるボタンは2種類あります．
Barrel : ペンの胴についているボタンです．OS標準ではマウス右ボタンと同じ信号を発生します．
Eraser : 消しゴムと呼ばれるボタンです．ペンの尻側についていることもあるようですが，Dynabook付属のペンはどれもBarelボタンとペン先端の間に配置してあります．OS標準ではこのボタンを押しながらペン先で画面をタッチドラッグすると消しゴムとして機能します．

InkPenHook はペンのボタンが押されたことを検知したときに指定されてキースキャンコードを発行し，かわりに本来のボタンの信号はできるだけもみ消します．
また，キースキャンコードの発行タイミングは2通りします．
Short : ボタンがメイクしてから指定時間内にブレイクしたことを検出した時に一度だけ発行します．
Long : ボタンがShort判定時間を超えて長い時間メイクを続けたことを検出した時．ブレイクするまでキーリピート信号を発行し続けます．
なお，ボタンが押されても対応するキースキャンコードを指定していない場合はOS標準のマウスイベントを妨げることなく素通りさせます．

InkPenHook はペンのボタンが押された時，ペン先の直下にあるウィンドウのプロセス名を調べ，それぞれに設定されたスキャンコードを発行します．

InkPenHook.xaml  このファイルは以上のような機能設定を定義する設定ファイルで，xamlフォーマットで記述します．
詳しくはサンプルファイルにコメントとして記してありますのでご一読ください．
このファイルはInkPenHookを起動したときに自動的に読み込まれます．InkPenHookをPCの起動時に自動起動するよう設定しておくことをおすすめします．
また，タスクトレイアイコンの右クリックメニューからファイルの再読み込みを実行することができます．


背景
Dynabook V8 (2-in-1 laptop PC Win11 )に付属しているスタイラスペン PS0087NA1PEN (AES1) および Dynabook F8に付属し，単体で購入可能なスタイラスペン PA5319U1PEN (AES2) はWACOM AESに準拠した仕様とのことです．
このPCを選ぶさい，WACOM製スタイラスが採用されていることが決めての一つでした．しかし私の考えは間違っていました．
OSベンダであるMicrosoft社はWindowsInk準拠の汎用デバイスドライバを組み込みましたが，サードパーティの同様の製品に含まれるようなリッチなツールやサプリメント機能は一切面倒をみてくれませんでした．
ハードウェアメーカであるDYNABOOK社も，AESライセンサであるWACOM社も，だれもこのスタイラスペンについてMicrosoft以上のサポートをしようとはしてくれませんでした．
つまり，このスタイラスペンは，ポインタズレのキャリブレーションも，筆圧カーブの調整も，そして，サイドボタン2この機能割り当ても，何も存在しません．この状態で出荷され，そのまま放置されています．

私はこのPCの他にデスクトップPCを使っていて，そこではXPPEN社の液晶タブレットでX3スタイラスペンを接続しています．このペンはサイドボタンに自由に機能を割り当てられてます．同じ操作性をDynabookでも再現したかったのですが，
叶いませんでした．OS標準機能の範囲では，ペンのボタンはマウスの右クリックとしてしか使えず，消しゴムボタンは押し続ける必要がありました．
そんなばかな．散々調べて手当たり次第に問い合わせして，そして打つ手がすべてなくなった時私は心底このPCを買ったことを後悔しました．
ほ　ん　と　う　に　が　っ　か　り　し　ま　し　た．

それでもそうやすやすと廃棄したり買い替えたりする余裕はありません．消しゴムを使うたびに感触の悪い硬いボタンを押し続けなければならず，指が腱鞘炎になりかけても私には我慢することしかできませんでした．
そしてある日，思い詰めた私はやけになってGoogle先生にぐちをこぼしてしまいました．
「このF**Kペンのボタンを何とかすることはできないですか？指が痛くて死にそうです」
するとGoolgeGemini先生はこう答えて言いました．「ペンやマウスの信号を捕まえて目的の機能にすり替える方法がいくつかあります．試してみたいですか？」
それから約2ヶ月の間，google先生を頼りに何種類もの方法を試しては破棄を繰り返しました．そしてやっとそこそこに動作する方法にたどりつきました．それがこのInkPenHook.exeです．
まだXPPENの軽快さには遠く及びません．ときどきボタン信号を取りこぼして錯乱したりすることもあります．けどまあ，ひとまずアップロードすることにしました．
